# AGENTS.md — elin-decompile-toolkit repo conventions

Most agents read this file automatically as project context. The operational workflows (first-time setup, version diffing, knowledge-base building, the full pitfall log) live in [SKILL.md](SKILL.md) and are not repeated here; when the two disagree, `SKILL.md` wins.

## What this repo is

An Agent Skill that teaches an AI agent to extract official data from a locally installed copy of Elin and decompile its source. The repo root is the skill itself; users install it with `npx skills add piexian/elin-decompile-toolkit`, or by copying the whole directory into their agent's skills directory.

```
SKILL.md     agent entry point (frontmatter + workflows + iron rules + version-diff lessons + pitfalls)
AGENTS.md    this file
README.md    human-facing install guide (Chinese)
README_en.md human-facing install guide (English)
scripts/     11 Python scripts (standard library only, no third-party dependencies)
```

## Data generated by the scripts (not committed, see .gitignore)

| Path | Contents | Produced by |
|---|---|---|
| `data/lang/` | official Chinese language pack, 83 tables | `python scripts/lang_xlsx_to_json.py data/lang` |
| `data/things.jsonl` `recipes.json` `materials.json` | items / recipes / materials | `python scripts/extract_things.py data` etc. |
| `src/Elin.decompiled.cs` | decompiled main DLL | `ilspycmd` + GBK→UTF-8 re-encode, see SKILL.md |
| `kb/` | RAG corpus and AstrBot upload chunks | `python scripts/build_corpus.py` etc. |

## Key locations

| Resource | Location |
|---|---|
| Main game DLL | `<game dir>/Elin_Data/Managed/Elin.dll` |
| Binary game data | `<game dir>/Elin_Data/sharedassets0.assets` |
| Official Simplified Chinese language pack | `<game dir>/Package/_Lang_Chinese/Lang/CN/` |
| Decompiled-code docs site (may lag the local version) | https://code.elin-modding.net/ |

The game directory is located automatically by `scripts/steam_locate.py` (`ELIN_GAME_DIR` env var first, then the Steam registry + `libraryfolders.vdf` + `appmanifest_2135150.acf`); run `python scripts/steam_locate.py` to verify on its own.

## Iron rules

1. **Names must come from the official language pack in `data/lang/` — never self-translate.** External wikis (Ylvapedia etc.) only provide structural hints; keep the English/Japanese original marked "awaiting official translation" when no Chinese exists.
2. **Mechanics conclusions must be grounded in decompiled code or game data.** Community wikis are leads only. Mark numbers that cannot be measured from data as "estimated".

## Modifying this skill

- After changing any script, repackage and re-verify in a clean directory; the verification steps and expected values live in the maintainer's workspace guide (not in this repo).
- The `SKILL.md` frontmatter only uses the two universal fields `name` + `description` — do not add agent-specific keys; keep the trigger words in `description` (Elin mechanics / official Chinese names / version changes / knowledge base).
- Known pitfalls (GBK re-encoding, the `*r` placeholder, AstrBot's chunking rules, `/tmp` paths, …) are recorded in `SKILL.md` under "Known pitfalls" — add new ones there when you fix them.
